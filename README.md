# My Favorite Series: Avatar: The Last Airbender

## About the Series
**Avatar: The Last Airbender** is an animated fantasy series about a boy named *Aang* who must master all four elements to restore balance to the world.

> "Water. Earth. Fire. Air. Long ago, the four nations lived together in harmony."

## Main Characters
1. Aang
2. Katara
3. Sokka
4. Toph

## Why I Like It
- Great storytelling
- Memorable characters
- Amazing soundtrack
- Strong themes of friendship and growth

### Favorite Episode
My favorite episode is *"The Blind Bandit"* because it introduces **Toph**.

### Fun Fact
The show has 3 seasons, called `Book One: Water`, `Book Two: Earth`, and `Book Three: Fire`.
